🔄 2. 콘텐츠 순환 루프

📋 3. Paste Pipeline — Claude Code → 티스토리

🟢 가동 중. Tistory API 없음 → Paste Pipeline으로 대응. 자동화 ROI 음수 → 사람 5-Click.
Step 1 — LLM 대화 → .md 로그 (ParksyCapture)

Claude Code·Grok 대화 종료 시 ParksyCapture가 자동 캡처 → logs/YYYY/MM/topic.md.

LLM 세션 → ParksyCapture (자동) → logs/2026/08/topic.md

AI 자동

Step 2 — .md → HTML 변환 (출판부)

parksy_to_html.py가 마크다운을 Tistory 호환 HTML로 변환. 아코디언·CSS-only 인터랙션·다크모드.

logs/2026/08/topic.md → parksy_to_html.py → /tmp/topic.html
Step 3 — Telegram sendDocument 전송 (v5.0)

log_to_telegram.sh — 두 가지 모드:

bash log_to_telegram.sh logs/2026/08/topic.md
# → sendDocument .md 첨부 → Tistory 마크다운 모드
bash log_to_telegram.sh --html logs/2026/08/topic.md
# → 변환 → sendDocument .html 첨부 → Tistory HTML 모드

자동 GitHub Actions push 트리거

Step 4 — 👤 사람 5-Click 수동 발행

Tistory API 미제공. Playwright 자동화도 세션 쿠키 만료 등 유지비용 때문에 ROI 음수.

  1. 다운로드 — Telegram 첨부파일(.md/.html) 다운로드
  2. 복사 — 파일 열어 전체 복사 (Ctrl+A→Ctrl+C)
  3. 글쓰기 — 해당 티스토리 → 마크다운/HTML 모드
  4. 붙여넣기 — Ctrl+V
  5. 발행 — 카테고리 선택 → 발행
⏱️ 2~3분/파일 → 5채널 10~15분
개발 20h+유지보수 대비 Paste Pipeline ROI 우수.
대안 분석 — 왜 자동화를 안 쓰는가
방식 개발 유지 판정
티스토리 API — — ❌ 없음 (2024 종료)
Playwright GUI 20h+ 월2h ❌ ROI 음수
Paste Pipeline 2h 0 ✅ 최적해
네이버 API 4h 월0.5h ⏳ 보류
