  1. Claude Code: md 원본 읽기 → HTML 변환 (아코디언·탭·SVG·다크모드·user-select:all)
  2. minify: 공백 최소화 → .txt 파일 저장
  3. TG 전송: sendDocument .txt (content_type: text/plain)
  4. Boss: TG에서 .txt 열기 → 전체 복사
  5. 티스토리: 글쓰기 HTML 모드 → 붙여넣기 → 카테고리 선택 → 발행
