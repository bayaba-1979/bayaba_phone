📝 Tistory 사고흐름 — 32건 (6 Flow) · CSS-only 풀인터랙티브

❗ 오해 금지: Tistory라고 "경량 텍스트"가 아니다. 티스토리 HTML 모드 한도 내에서 최대 인터랙티브. JS만 빠지고 <details> 아코디언·:checked 탭·:target 모달·SVG 다이어그램·CSS 애니메이션·다크모드 전부 들어간다. 코드 블록은 user-select: all로 탭 한 번에 전체 선택. GitHub Pages와 동일한 수준의 시각적 완성도, JS 유무만 다르다.

🔗 연결 구조 — Hub ↔ Tistory

Hub → Tistory
각 기술 페이지 하단에 "이 결정이 어떻게 내려졌는가" 링크 — 해당 Tistory Flow로 연결
Tistory → Hub
각 회의록/세션로그 상단에 "이 주제의 최종 교재" 링크 — 해당 Pages Chapter로 연결
🔑 핵심: 독자는 교재(Hub)를 보며 "어떻게"를 배우고, 필요하면 사고흐름(Tistory)로 넘어가 "왜 이렇게 했는지"를 이해한다. 두 레이어가 하나의 완결된 지식 체계를 이룬다.
