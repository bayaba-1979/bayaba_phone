4. 1회 설정 작업

A. 블로그 스킨 (내가 CSS 파일 제공)

  • 관리자 → 스킨 편집 → HTML/CSS 붙여넣기
  • 웹진 스타일: 깔끔한 타이포그래피, 강조 색상, 링크 카드 스타일

B. 서식 등록 (네가 에디터에서)

  • 네이버 글쓰기 → 헤더·푸터·링크 박스 배치 → "서식으로 저장"
  • 매주 새 글 쓸 때 "서식 불러오기"로 재사용

C. YouTube 재생목록

  • "웹진 클립" 플레이리스트 생성
  • 짧은 설명 클립 전용 보관
