디스코드 API 자동화 키포인트

  • 로그인: POST /api/v9/auth/login → user token
  • 서버 생성: POST /api/v9/guilds → {"name":"..."}
  • 채널 생성: POST /api/v9/guilds/{id}/channels
  • 위젯: PATCH /api/v9/guilds/{id}/widget

  • 초대링크: POST /api/v9/channels/{id}/invites
