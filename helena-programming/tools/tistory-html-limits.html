🧪 Tistory HTML 모드 — 기술 한도

티스토리 글쓰기 HTML 모드에서 가능한 것과 불가능한 것 전부
(스킨 편집 아님 — 스킨 편집은 JS·CSS 모든 게 자유)

XSS 필터 = JS만 막는다. CSS·SVG는 통과.

⚖️ 스킨 편집 vs 글쓰기 HTML 모드

항목스킨 편집 (skin.html)글쓰기 HTML 모드
<script>✅ 가능❌ 전부 제거
<style>✅ 가능✅ 가능
이벤트 핸들러 on*✅ 가능❌ 속성 제거
SVG 인라인✅ 가능✅ 가능
CSS 애니메이션✅ 가능✅ 가능
data-* 속성✅ 가능✅ 가능
<iframe>✅ 가능⚠️ 제한적
HTML5 시맨틱✅ 가능✅ 가능
핵심 원칙: 티스토리 글쓰기 HTML 필터는 XSS 방지가 유일한 목적이다. JS 실행 경로만 차단하고, CSS 표현·SVG 그래픽·HTML 구조는 건드리지 않는다.

✅ 완전 지원 — 안심하고 써도 되는 것

HTML 요소

<article> <section> <header> <footer> <nav> <details> <summary> <figure> <picture> <audio> <video> <table> <mark> <time> <abbr> <blockquote>

CSS — 전부 가능

Flexbox, Grid
display: flex; display: grid; gap; place-items; align-content; ...
애니메이션
@keyframes, animation, transition — 전부 가능. JS 없이도 진입 애니메이션, 프로그레스 바, 타이핑 효과 등 구현.
CSS 변수 + 계산
:root { --color: #333; }, calc(), counter(), @media 쿼리 — 전부 가능.
가상 선택자 (인터랙션)
:hover, :focus, :target, :checked, :nth-child(), :not(), ::before, ::after — 이게 JS를 대체하는 핵심.
폰트
@import url('https://fonts.googleapis.com/...') — 대부분 통과. 불안하면 구글 폰트 CSS를 직접 <style> 안에 @font-face로 복사.

SVG — 인라인 전부 가능

<svg viewBox="0 0 800 600" xmlns="http://www.w3.org/2000/svg">
  <circle> <rect> <path> <line> <polyline> <text> <tspan>
  <g> <defs> <use> <symbol>
  <linearGradient> <radialGradient> <pattern> <clipPath> <mask>
  <filter>  <!-- SVG 필터(드롭섀도우 등) -->
  <style>  <!-- SVG 안에서도 CSS 사용 가능 -->
  <animate> <animateTransform>  <!-- SMIL 애니메이션 (테스트 필요) -->
</svg>

❌ 완전 차단 — 시도해도 사라지는 것

JavaScript 관련 (전부 막힘)

<!-- 전부 제거됨 -->
<script>...</script>
<script src="..."></script>
<button onclick="...">
<body onload="...">
<img onerror="...">
<a href="javascript:...">        <!-- javascript: URL 차단 -->
<svg><script>...</script></svg>  <!-- SVG 안 script도 제거 -->

이벤트 핸들러 속성 (전부 제거)

onclick onload onerror onmouseover onmouseout onfocus onblur onchange oninput onsubmit onkeydown ontouchstart onwheel oncopy ondrag

on* 속성은 완전히 제거되지만, data-* 속성은 보존된다. data-*는 HTML5 표준이라 XSS 위협으로 분류되지 않음. JS 없이도 CSS 선택자로 data-* 값을 읽을 순 없지만, 마크업 메타데이터 용도로 유용.

⚠️ 회색 지대 — 환경 따라 다름

항목통과 확률비고
<iframe>중간티스토리 정책 따라 차단 가능성
<embed>, <object>낮음보안상 차단 가능성 높음
body 내 <link>중간HTML 스펙 위반이지만 통과 가능성
CSS @import높음대부분 통과. 실패 시 @font-face 직접 사용
<canvas>낮음JS 없으면 무의미해서 필터가 제거할 수도
<form> + <input>요소는 남음JS 없으니 제출 불가, UI 요소로만
SVG <animate>중간SMIL. 브라우저 지원하나 티스토리 미지원 가능
CSS :has()브라우저 의존2023년 말 크롬 지원. 구형 WebView 제외
CSS @property브라우저 의존Houdini. 크롬 85+
<meta> 태그낮음body 영역에서 제거 가능성
<!-- --> 주석높음HTML 주석은 남음. IE 조건부 주석만 제거

🧪 발행 후 확인 체크리스트

아래 코드를 HTML 모드로 글 발행 후, 실제 발행된 페이지에서 DevTools(F12)로 확인.

  1. <style> 생존 — 빨간색 텍스트가 보이면 통과
  2. <details> 작동 — 클릭해서 열리면 통과
  3. :target 작동 — 링크 클릭 시 배경색 바뀌면 통과
  4. SVG 생존 — 파란 원이 보이면 통과
  5. data-* 속성 — DevTools로 확인
  6. @import 폰트 — Noto Sans KR 적용 확인
  7. <iframe> — 보이면 통과, 없으면 차단
제거된 요소는 소스에서 흔적도 없이 사라진다. 없는 걸 확인하려면 원본과 발행본을 diff.

🎯 실전: JS 없는 풀인터랙티브 패턴 6종

① 아코디언 대화록

<details> per 턴. 화자별 좌측 컬러 바. 열릴 때 transition.

② 탭 필터

숨은 radio + :checked ~ .list. 전체/Boss/Gap만 보기.

③ SVG 사고 지도

inline SVG 결정 트리·타임라인. :hover 노드 강조. data-* 메타.

④ CSS 그래프

flex + --h 커스텀 프로퍼티 바 차트. @keyframes 성장 애니메이션.

⑤ 타임라인

border-left 줄기 + ::before 원 마커. 결정 지점 강조.

⑥ 카드 그리드

Fact/Feel/Gap/Fix/Next grid. :hover translateY.

📦 결론: 티스토리 HTML 모드 최대치

계층가능 여부핵심
HTML5 구조✅ 전부시맨틱·아코디언·표·미디어
CSS 표현✅ 전부Grid·Flexbox·애니메이션·변수·미디어쿼리
SVG✅ 인라인 전부모든 벡터 요소 + CSS 호버
CSS 상태✅ 전부:target, :checked, :hover, :focus
CSS 가상요소✅ 전부::before, ::after, ::marker
JS 인터랙션❌ 전부 불가<script>, on*, javascript:
외부 리소스⚠️ 대부분이미지·폰트·오디오 URL 통과, iframe 의심
최대치 = JS 없이 CSS+SVG+HTML5만으로 구현 가능한 모든 인터랙션.
<details>, :target, :checked, SVG CSS animation, @keyframes, Grid, Flexbox — 이 조합이면 인포그래픽·대시보드·인터랙티브 기사 수준의 페이지를 JS 없이도 만들 수 있다.
