# 코딩 에이전트 신규 옵션 검토 — 결론: 5종 폐기, 기존 로스터 확정

> **결론부터:**
> - 공짜 에이전트 5종 서치·검토 → **전부 "안 되겠다" (폐기)**.
> - **확정 로스터:** 코딩 = Claude Code(주력) + Aider(1개) / 생성 = Grok 구독(GPU 이미지·영상 전용).
> - **보험 1줄:** DeepSeek가 비싸지면 Qwen(알리바바, 현재 무료)으로 스왑.
> - **프라이버시 원칙:** "어느 나라"가 아니라 "어느 레인" (아래 §4).

---

## §1. 신규 5종 (Boss 원문 리서치)

| # | 에이전트 | 라이선스/가격 | 핵심 | 단점/주의 |
|---|---|---|---|---|
| 1 | **OpenCode** | MIT (193K stars) | BYOK, 가장 많이 쓰이는 OSS 코딩 에이전트, DeepSeek 조합 = Aider 대체 | — |
| 2 | **Qwen Code** (알리바바) | API 현재 무료 (보조금) | GLM-5 SWE-bench 77.8%, 한국어 주석/문서화 강함 | (초기 메모: 중국 서버 — §4에서 정정) |
| 3 | **Antigravity CLI** (Google) | 개인 무료 티어 (2026-05-19 GA) | Gemini CLI 교체본, Workspace 연동 | Gemini 의존 |
| 4 | **Cline** (VS Code) | 무료, BYOK (5M 설치) | Claude/DeepSeek/Gemini 전부 | **IDE 전용 → 터미널 아님** |
| 5 | **Kilo Code** | $15/user/월, MIT | API 마크업 없는 BYOK 게이트웨이, 팀 공유 | 유료 |

**판정: 5종 전부 폐기.** 이유 — Cline은 IDE 전용이라 S21 터미널에서 못 돔. OpenCode·Antigravity·Kilo는 "돌긴 하나 DeepSeek 엔진 아래 능력이 안 늘거나 / 생태계가 다르거나 / 불필요한 유료". Qwen만 §3 보험으로 남김.

## §2. 확정 로스터 (2026-08-14)

| 레인 | 구성 | 근거 |
|---|---|---|
| 코딩 | Claude Code(주력) + Aider(1개) | 에이전트는 "더 많은 도구"가 아니라 "하나 엔진 + 하나 실행자"면 충분 |
| 생성 | Grok 구독 | GPU 이미지/영상(image_edit·I2V)은 코딩 에이전트가 못 하는 *생성* 일 → 렌탈(백서 87 §1-2) |

## §3. 보험 — BYOK 원리 (오늘 스터디의 유일한 수확)

에이전트 도구는 BYOK(모델 무관)라 **모델을 갈아끼울 수 있다** → 모델은 스왑 가능한 소모품.

```
지금:  DeepSeek (제일 싼)        ← 주력
보험:  Qwen/알리바바 (현재 무료)  ← DeepSeek 비싸지면 갈아끼움
```

이 한 줄이면 충분. 나머지 4종은 스터디의 중간 산출물.

## §4. 프라이버시 원칙 — "어느 나라"가 아니라 "어느 레인"

- **돌봄 레인** → 외부 모델 자체를 안 탐(국적 무관) → 안전.
- **코딩/소망 레인** → 어차피 공개 콘텐츠 → 누가 학습에 쓰든 무관.
- 따라서 국적(중국/미국)으로 특정 제공자를 폄하할 이유 없음. 미국 회사(엔트로픽·오픈AI·구글)도 소비자 채팅은 기본 학습에 씀.
